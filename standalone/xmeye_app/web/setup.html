Remote access

See the cameras away from home through a Cloudflare Tunnel. Nothing is opened on your router. Everyone logs in with the web password.

In the Cloudflare dashboard: Zero Trust → Networks → Tunnels → Create a tunnel (cloudflared). Copy the token from the install command. Add a public hostname with the service http://localhost:18765.

Live video goes over HLS through the tunnel: a few seconds behind, but it works on any network.
